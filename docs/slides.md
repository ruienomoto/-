- さらに消費税、固定資産税…

## 給付が少なすぎる

- ベーシックインカムは存在しない
- 給付金は必要な人に届かない

```
税金は高く取られている
         ↓

         ↓
   差分は「どこへ」行っている？
```

# 【Section 1】
## 通貨と信用の基本構造

---

# 通貨とは何か？

「お金」という理解では不正確です。正確には：

> **通貨とは：「取引の仲介手段」であり、「信用の表現形態」**

100円玉を持つとき、それは：

- 「日本社会において、100円分の価値と交換する権利がある」

ということを意味します。

---

# 歴史的転換点：1971年

## かつて（金本位制）
- 1ドル = 金○グラム という固定関係
- 通貨は「金」に裏付けられていた

## 1971年以降（現在）
- **ニクソン・ショック** で金本位制が廃止
- 通貨は「何に支えられているのか？」

→ **答え：その国の「信用」**

---

# 円の価値はどこから来るのか？

なぜ100円は「100円の価値」を持つのか？

1. 日本が「円を発行する権利」を持っているから
2. 日本が「法的に円での取引を定め」たから
3. 日本が「税金を円で払わせ」、円に需要を作り出しているから
4. 「日本という国が続く限り、円は使用可能」だから

$$\text{円の価値} = \text{日本という国家の信用}$$

---

# 信用の三つの源泉

| 信用の源泉 | 説明 | 例 |
|-----------|------|-----|
| **労働・生産** | 価値を作り出す能力に基づく信用 | 日本の製造業、技術力 |
| **資産・担保** | 返済能力を示す資産 | 中央銀行の金準備、政府資産 |
| **制度・法的権力** | 強制力を持つ組織の約束 | 政府の「税金を取立てる権力」 |

---

# 現在の信用配置

| 主体 | 役割 | 信用の源泉 |
|-----|------|----------|
| **中央銀行** | 通貨発行 | 国家の金融機関としての信用 |
| **政府** | 国債発行・税収 | 「税金で返す」という約束 |
| **主権者（市場）** | 消費・投資 | 経済活動による価値創造 |

> 政府が調達できる資金は **「国民が稼ぐ範囲内」** に限定される

---

# プライマリーバランスという制約

「プライマリーバランス」＝ 税収と支出を一致させる目標

この目標が掲げられると…

```
給付を充実させたい
        ↓
税金を上げるしかない
        OR
税金を上げない → 給付を削るしかない
```

**この二者択一は、「制度設計」から来る必然的な矛盾**

---

# 現在の制度の限界

## 一極集中構造

- 「信用」が **政府と中央銀行に集中**
- 「市場」の信用はほぼ使われていない

## 弊害

- **柔軟性がない**：税金と国債の二手段しかない
- **インフレ圧力**：国債を無限には発行できない（信用が失われる）
- **再分配機能が限定的**：税金では「再分配」しかできず「信用創造」ができない

---

<!-- _class: section-header -->

# 【Section 2】
## 三つの主体の役割

---

# 三つの主体とは？

現代の経済を動かす三者：

```
       ┌──────────────┐
       │   中央銀行    │  通貨の流通量管理・金融安定
       └──────┬───────┘
              │
    ┌─────────┼─────────┐
    ▼                   ▼
┌────────┐         ┌──────────┐
│ 政府   │         │主権者    │
│       │◄───────►│（市場）  │
└────────┘         └──────────┘
財政・再分配       価値創造・消費・投資
```

---

# 中央銀行の役割

## 本質的機能
> 通貨流通量の管理と金融システムの安定を担当する機関

## 現在の制約
- 「政府と独立」した機関として位置づけ（日本銀行）
- 政府の指示に直接従わない
- 「金融政策の独立性」を名目に通貨供給量を管理

## 信用の源泉
- 流動性管理能力
- 金融システムの安定維持力

---

# 政府の役割

## 本質的機能
> 「税金を徴収する権力」と「支出を決定する権力」を持つ組織

## 担う機能
- **再分配**：所得を税金を通じて再配分
- **公共投資**：インフラ・サービス
- **社会保障**：医療・年金・生活保護
- **政策実行**：経済政策・社会政策

## 信用の源泉
- **強制力**（税金を取立てる権力）
- 国民の合意と法的権力

---

# 主権者（市場）の役割

## 本質的機能
> 価値を創造し、取引を行う主体のすべて

## 生み出す信用
- **労働による信用**：仕事をして給料をもらう
- **生産による信用**：企業が商品を作り、売る
- **投資による信用**：新ビジネスや技術に投資する

## 現在の限界
- 市場は「信用を発行する主体」として認識されていない
- 個人や小企業は直接「信用」を発行できない

---

# 問題の核心

```
政府が国債を発行できるのは「政府の信用」の範囲内
              ↓
   政府の信用 = 「税金で返す」という約束
              ↓
      税金 = 国民の所得から来る
              ↓
   政府が調達できる資金は「国民が稼ぐ範囲内」
```

> **もし「別の信用源泉」を活用できたら？**

その答えが **「三すくみ国家貨幣制度」** です。

# 【Section 3】
## 三すくみ国家貨幣制度の提案

---

# 「三すくみ」とは何か？

「三すくみ」 ＝ 三者が互いに相手を牽制している状態

例：じゃんけん（グー・チョキ・パー）

> **「三すくみ国家貨幣制度」とは：**
> 通貨は一つ（円）であるが、
> その発行と信用の源泉を**三つの主体に分散**させる制度

---

# 三すくみ制度の構成

| 主体 | 発行するもの | 信用の源泉 | 役割 |
|-----|------------|----------|------|
| **中央銀行** | 中央銀行通貨・中央銀行債 | 流動性管理 | 安定性を確保 |
| **政府** | 政府通貨・国債 | 税徴収権・政策実行力 | 財政・再分配を実行 |
| **主権者（市場）** | トークン型円・民間証券 | 労働・生産・投資 | 成長・イノベーション |

---

# 最重要原則：「通貨は一つ」

三すくみ制度の最も重要な特徴：

> **通貨はすべて「円」**

- 中央銀行が発行する通貨 → **円**
- 政府が発行する通貨 → **円**
- 市場が発行するトークン → **円**

**すべて等価に交換可能**

→ 流通が統一され、混乱が生じない

---

# 相互牽制のメカニズム

```
        中央銀行
       ↗        ↖
      /            \
  政府  ←────────→  市場（主権者）
```

| 牽制の対象 | 牽制する主体 | 手段 |
|-----------|------------|------|
| **政府の暴走を防ぐ** | 中央銀行 | インフレ防止で通貨供給制限 |
| **政府の暴走を防ぐ** | 市場 | 信用喪失で政府通貨を拒否 |
| **中銀の独走を防ぐ** | 政府 | 政策実行で対抗 |
| **市場の投機を防ぐ** | 政府 | 規制 |
| **市場の投機を防ぐ** | 中央銀行 | 金融政策 |

---

# 財源の再定義

## 従来の制度
```
財源 = 税金 + 国債
```
政府の支出は「税金で返す」という約束に制約される

## 三すくみ制度
```
財源 = 税金 + 国債 + 政府通貨発行
```
政府の支出は「**社会全体の信用の総和**」によって制約される

> **従来の「政府の財源」→「社会全体の信用」へ転換**

---

# ベーシックインカムの実現

三すくみ制度のもとで、BI（基本所得）をどう実現するか？

```
Step 1: 市場（主権者）が「トークン型円」を発行
               ↓
Step 2: 中央銀行がそれを引き受け、同額の通貨を供給
               ↓
Step 3: 政府がその通貨を全国民にBIとして配布
               ↓
Step 4: 通貨は「納税」や「消費」を通じて回収
```

> このプロセスで「新しい信用」が生まれ、
> かつ「インフレは抑制される」

---

# よくある質問 Q&A

**Q1. インフレにならないのか？**
> 発行量を生産能力に連動させることでインフレを防ぐ。
> 三つの信用源泉が相互に牽制するため、過度な発行は自動的に制限される。

**Q2. 現実に導入できるのか？**
> 法的枠組み・国民的合意・段階的導入により、十分に可能。
> 日本の高い教育水準と法治主義が有利に働く。

**Q3. 国際的な問題は？**
> IMF体制下での調整が必要だが、「通貨制度は各国の主権」という原則に基づき、国際的対話で解決可能。

---

# 実装上の課題

## トークン発行の裏付け
市場が将来の「**生産力**」を担保にトークンを発行

## 等価交換性の確保（1円 = 1円）
- 過度な発行を防ぐ（インフレ防止）
- 各主体の信用が相互に破綻しないようにする
- 流動性の確保

## 移行期の設計
1. 法的枠組みの整備
2. 国民への説明と合意形成
3. 金融システムの改革
4. 国際的な調整

---

# 期待される社会への影響

| 効果 | 内容 |
|-----|------|
| **ベーシックインカム実現** | 誰もが最低限の経済的自由を得る |
| **地方交付金の充実** | 自治体が主体的に政策を実行できる |
| **投資の促進** | 新しい信用源泉により、イノベーションが活性化 |
| **政治的安定** | 互いに牽制する三主体により、独裁が防止される |
