## 1. 勉強会の概要

### 勉強会名
**「財源問題を解決するための勉強会」**
サブタイトル：三すくみ国家貨幣制度による根本的解決

### 目的

参加者が以下の状態に到達することを目的とする：

- 三すくみ国家貨幣制度が日本の財源問題を根本的に解くことの論理的必然性を理解する
- その理由を他者に説明できる状態に到達する
- 現在の「税が高い、給付が少ない」という状況の構造的原因を認識する
- 「政府支出はお金を作る行為」という貨幣の正体を理解する

### 対象者

- 財源問題に関心がある人
- プライマリーバランス目標による地方交付金縮小に影響を受けている人
- 経済的自由やベーシックインカムに関心がある人
- 金融知識はほぼないが、現状に疑問を持つ人

### 開催形式

| 項目 | 内容 |
|-----|------|
| セッション数 | 全1回（入門版）/ 全12回（完全版） |
| 構成 | 講義 ＋ 質疑応答 ＋ ワークショップ |
| 対象規模 | 20〜50名推奨 |
| 準備物 | プロジェクター、ホワイトボード（3色マーカー）、参加者用ワークシート |
| 所要時間 | 約2時間（全1回版） ／ 全12回（各60分） |

## 2. 理論的背景

### 苫米地理論・定理1フレームワークの適用

**定理1とは**

「人間の認知状態は、評価関数V(x,t)の時間積分を最小化することで、Total Comfort Zone（TCZ）へと収束する」

```
π_c(x) = arg min_{u(t)} ∫₀ᵀ V(x(t),t) dt → x*(t) → TCZ
```

**参加者の初期状態（x₀）——高い不安定性**

- 「なぜ税金は高いのか」という違和感
- 「給付金が少ない、もらえない」という不安定性
- 「ベーシックインカムなしでは生きていけない」という経済的困難
- 従来の金融・財政の説明では満足できない認知的葛藤

**到達目標（TCZ）——安定した確信**

- 「お金はどこから生まれるか」を正確に理解している
- 「三すくみ国家貨幣制度」の仕組みを理解している
- それが財源問題を解く論理的必然性を確信している
- 他者に説明できるレベルの安定した知識を持っている

### 評価関数V(x,t)の軌跡

| 時間フェーズ | V(x,t)の状態 | 参加者の認知状態 |
|------------|------------|--------------|
| 開始前（t=0） | V高い | 「税が高い。なぜ？」「給付が少ない。なぜ？」 |
| Section 1終了 | V中程度 | 「お金がどう生まれるかが見えてきた」 |
| Section 2終了 | V低下中 | 「政府・中央銀行・市場の役割が理解できた」 |
| Section 3終了 | V最小 | 「三すくみ制度の必然性を理解・確信」 |
| ワーク後 | TCZ安定 | 「友人に説明できるレベルに到達」 |

## 4. 参加者が獲得する四つの確信

**① お金の正体の理解**
政府支出はお金を「使う行為」ではなく「作る行為」。
銀行の貸出が信用創造によってお金を生む。

**② 構造的理解**
財源問題は「お金がない」のではなく、「信用構造の設計の問題」であることを理解

**③ 論理的必然性**
三すくみ構造が必然的に財源問題を解くことを論理的に確認

**④ 説明能力**
他者に「なぜ三すくみなのか」を説明できるレベルの知識を習得

## 7. 設計思想

### 三つの設計原則

**① 参加者中心**
講師が「教える」のではなく、参加者が「理解への欲求に基づいて自然に学ぶ」環境を提供

**② 構造的理解**
「なぜそうなるのか」という論理的必然性を、あらゆるレベルで説明
特に「お金の生まれ方」という根本から積み上げる

**③ 実践的定着**
ワークショップを通じた「説明演習」により、知識を確実に定着させる

### 継続学習の推奨

一度の講義で終わりではなく、継続的な学習コミュニティが重要。

推奨アクション：
1. 教科書を読み返す
2. 友人3人以上に説明する
3. 全12回カリキュラムへの参加
